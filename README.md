## 🇨🇳 中文

这是一个邮箱技能，覆盖起草邮件、写草稿、发送、回复、转发、查阅和搜索邮件，也管理邮件文件夹、邮件标签和邮件联系人，并能监听新邮件、维护收信规则。它把邮件内容明确当作不可信的外部输入，用安全规则约束处理方式。数据真实性与操作合规是硬要求：找不到就报「未找到」，不得伪造结果。所有写操作前都要显式确认，文档还给出正确流程示例。技能只服务邮件意图，不越界到文档、表格、日历、认证配置、纯联系人查询或聊天任务。

### ✨ 能做什么

- 起草邮件、管理草稿、发送 / 回复 / 转发
- 查阅与搜索邮件，管理文件夹、标签、邮件联系人
- 监听新邮件并维护收信规则
- 邮件内容按不可信外部输入处理，附安全规则
- 查不到只报「未找到」，禁止伪造结果
- 所有写操作前显式确认，并给出正确流程示例

## 🇬🇧 English

An email skill for drafting, sending, replying, forwarding, reading, and searching mail, plus managing folders, labels, and contacts, listening for new messages, and maintaining inbox rules. It treats email body content as untrusted external input and wraps handling in explicit safety rules, with data-truthfulness and compliance requirements: if something is not found, report 'not found'—never fabricate. Every write operation requires explicit confirmation first, and the documented flow shows the correct sequence. It is deliberately scoped to mail intent only.

### ✨ What it does

- Draft mail, manage drafts, then send, reply, or forward
- Read and search mail, manage folders, labels, and mail contacts
- Listen for new mail and maintain inbox rules
- Treats message content as untrusted external input, with safety rules
- Reports 'not found' instead of inventing a result
- Requires explicit confirmation before any write, with a worked flow example
